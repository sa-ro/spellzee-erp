# `academic` — Curriculum, Lessons, Assessment

**Phase 2.** Baseline §17, §18.

Empty on purpose. The directory exists so academic concerns have an obvious home before anyone is
tempted to put a lesson record in `operations`.

## Will own

Curriculum, lesson plans and records, topics taught, activities, homework, worksheets and
materials, assessments, teacher academic feedback, progress, recordings, and the teacher-handover
context pack (§18).

## Four concepts that must stay distinct

§17.1 is explicit, and blurring these is the classic mistake:

| | |
|---|---|
| **Attendance** | whether/how much the student attended — `operations` |
| **Lesson** | what was taught — here |
| **Assessment** | how the student performed — here |
| **Progress** | whether the student is improving — here |

Four records, not one. Attendance in particular belongs to `operations`, not here.

## Blocked

The academic curriculum and assessment model (§30.12) is genuinely shape-blocking for these tables —
but it is Phase 2, so it must not leak into a Phase 1 schema.
