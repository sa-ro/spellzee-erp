## Widely-Recognized Community Standards
- **Architecture Decision Records (ADR) — Michael Nygard's original template and the broader ADR community practice** — the short, dated, decision-plus-rationale format referenced in Rule 10
- **Keep a Changelog (keepachangelog.com)** — the widely-adopted changelog format and convention referenced in Rule 19
- **TSDoc** — the standard comment syntax for documenting TypeScript exports, consumed by editor tooling and documentation generators: https://tsdoc.org
