## Official Documentation

- **Shaka Player official docs** — DRM/EME integration (Widevine/PlayReady/FairPlay), offline playback: https://shaka-player-demo.appspot.com/docs/api/index.html
- **Vidstack (`@vidstack/react`) official docs** — accessible player shell, theming, media provider architecture: https://www.vidstack.io/docs
- **Video.js official docs** — plugin ecosystem, accessible controls: https://videojs.com/guides
- **W3C — Encrypted Media Extensions (EME) specification** — the underlying browser DRM API: https://www.w3.org/TR/encrypted-media/
- **WebVTT (WHATWG/W3C) specification** — caption/subtitle track format: https://www.w3.org/TR/webvtt1/
- **MDN — Autoplay guide for media and Web Audio APIs** — browser autoplay policy behavior referenced by Rule 12: https://developer.mozilla.org/en-US/docs/Web/Media/Autoplay_guide

## Widely-Recognized Community Standards

- **CMCD (Common Media Client Data) / QoE instrumentation conventions** — the basis for the QoE-analytics event set referenced by Rule 10: https://cta.tech/Resources/Standards/CMCD
