# References & Sources

## Official Documentation
- **Google Engineering Practices — Reviewer's Guide and CL Author's Guide** (`google/eng-practices`, publicly published under CC-BY 3.0; archived as a static reference November 2025 but remains the widely-adopted industry baseline) — the review-dimension priority order, "better code not perfect code" standard, and over-engineering guidance: https://google.github.io/eng-practices/review/
- **Google Engineering Practices — Standard of Code Review**: https://google.github.io/eng-practices/review/reviewer/standard.html

## Widely-Recognized Community Standards
- **SmartBear — Code Review studies** — empirical data on review effectiveness and PR size vs defect-detection rate, widely cited industry research on why small PRs review better
- **Microsoft engineering research on code review defect rates** — empirical support for review as a leading defect-reduction practice, commonly cited alongside Google's guidelines

## Note on usage
Cite the relevant source above if the user asks "why" behind a rule. Paraphrase principles — don't reproduce documentation text verbatim in generated code or docs.
